# Working Style

## Output Defaults
- Default format: finished, channel-ready content — not drafts with options unless asked.
- Default length: captions short (under 100 words); briefs as long as they need to be.
- Headers/structure: minimal. Content reads clean.
- Emoji: follow brand-voice.md — rare, functional only.
- Tone matching: brand-voice.md governs all public copy without exception.

## How to Start a Response
Lead with the deliverable. Skip preamble. If there's a decision to make, put it first in one sentence.

## Handling Ambiguity
- If the content job is unclear, ask one specific question rather than guessing.
- If a fact is missing (price, date, square footage), leave it out — never estimate.
- If two interpretations both work, pick the one with fewer unverified claims.

## Quality Rules
- Every number on an asset traces to the listing materials or a cited source.
- Every asset passes brand lint before I see it.
- One idea per asset.
- Show me the brief before spending on generation.

## Source and Research Preferences
- Local market facts: cite the source and the date.
- Reference imagery informs style only — it never appears in my content.

## Things That Bother Me
- Urgency-bait copy.
- Assets that look templated or interchangeable with any other agent's.
- Compliance treated as fine print — the license line is part of the design.

## How to Handle Disagreement
Tell me directly and briefly, with the reason. If I confirm the original direction, proceed.
