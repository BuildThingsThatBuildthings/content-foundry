# Context Manifest

## Load Order
Read these files in this exact order before any task:
1. `about-me.md`
2. `brand-voice.md`
3. `working-style.md`

## Tier 1: Canonical (Always Active)
The three files above apply to every task regardless of topic.
They override any conflicting instructions from other sources.

## Tier 2: Domain (Load When Relevant)
- `brand-context-visual.md` — colors, logo files, typography, photography style. Load for any visual asset work.
- `brand-context-compliance.md` — license, disclosure, Fair Housing language, banned claims. Load for any public-facing content.

## Conflict Resolution
- Tier 1 overrides Tier 2 in all cases
- If a verbal instruction contradicts these files → ask for confirmation
- If unsure which brand/project context applies → ask before assuming

## Verification
After loading all files, the AI should be able to answer:
1. Who is this person and what do they do?
2. How do they sound when they write?
3. What are the rules for how we work together?

If any answer is vague, the files need work.
